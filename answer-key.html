Answer Key & Marking Guide

Programming Readiness Test — 46 points + 3 bonus — TEACHER COPY

Section A: Quick Concepts (1 pt each)

A1. a) stores a value
A2. c) 15
A3. b) == (a single = assigns a value)
A4. b) 0 (zero-based indexing)
A5. b) False (a while loop runs until its condition becomes false; the count can vary)
A6. b) a for loop
A7. b) sends a value back to the caller. Watch for (a): Scratch kids often confuse returning with printing/say.
A8. b) "55". The string makes JS glue them together. Worth discussing afterward: Python would raise an error here instead — one reason types matter more in Python.

Section B: Trace the Code

B1. (2 pts) Prints 5 then 8.

Key idea: y was set when x was 4; changing x later does NOT update y. 1 pt per correct line.

B2. (2 pts) Prints teen.

Tests the ≥ boundary — 13 counts as a teen.

B3. (3 pts) Prints 10.

The accumulator adds 1+2+3+4. Common wrong answer: 4 (only the last i). Give 1 pt if they show the loop ran 4 times but added wrong.

B4. (3 pts) Prints hi, hi, hi, then 3.

2 pts for three hi's, 1 pt for the final 3. Common wrong answer: final value 2 (off-by-one).

B5. (3 pts) Prints dog then 3.

animals[1] is the SECOND item. 1.5 pts each. "cat" for the first answer means zero-based indexing has not landed.

B6. (4 pts) Prints six lines: 1-1, 1-2, 2-1, 2-2, 3-1, 3-2.

Full marks for all six in order. 2 pts for the right pattern with wrong order or count. This is the single best readiness signal on the test — students who can trace a nested loop are ready for Python.

B7. (3 pts) Prints 16.

double(3) is 6, double(5) is 10; the RETURN VALUES get added. 1 pt partial for one correct call.

Section C: Spot the Bug (3 pts each)

C1. The if uses = (assignment) instead of == (comparison), so it assigns "dragon" to password and the condition is always truthy.

Fix: if (password == "dragon"). 2 pts for spotting the symbol, 1 pt for the fix. (Bug Hunt 1 was the rehearsal for this.)

C2. lives is never decreased inside the loop, so the condition never becomes false — an infinite loop.

Fix: add lives = lives - 1; (or lives--) inside the loop. 2 pts for the missing update, 1 pt for the fix. (Savings Goal Counter + Bug Hunt 2.)

C3. Index 3 is out of range. With 3 items, valid indexes are 0, 1, 2 — the last item is colors[2].

Also accept colors[colors.length - 1] as a fix (praise it!). 2 pts for explaining zero-based indexing, 1 pt for the fix. (Playlist Stepper + Bug Hunt 3.)

Section D: Write Some Code

D1. (4 pts) Example: 
for (let i = 1; i <= 10; i++) {
  console.log(i);
}

Accept while loops and pseudocode. 4 pts = correct logic including bounds. 3 pts = off-by-one (prints 0–9 or 1–9). 2 pts = loop structure right, body wrong. Printing 0 to 9 is actually a GOOD sign of zero-based habits — just note it.

D2. (5 pts) Example: 
function greet(name) {
  return "Hello, " + name + "!";
}

Must use return, not console.log. 5 pts = parameter + return + correct string. Deduct 2 pts if they print instead of return — the most important distinction to catch before Python (Calculator Refactor + Bug Hunt 4 were the rehearsal). Deduct 1 pt for missing punctuation.

BONUS (3 pts) Example: 
function isEven(n) {
  return n % 2 == 0;
}

Also accept an if/else returning true/false. Any working logic gets full marks.
