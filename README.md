# Basic Web Dev Examples

Small, finished web pages for teaching kids the basics of **HTML, CSS, and JavaScript**.

**To run any example:** open its HTML file in a browser (double-click it). No setup required.
Each folder has its own README with teaching steps. The examples build on each other, so this is a good order to teach them in:

| # | Example | What you teach |
|---|---------|----------------|
| 1 | [Geological Wonders](./Geological%20Wonders/) | HTML tables and CSS styling (no JavaScript yet) |
| 2 | [Intro to HTML & CSS](./Intro%20to%20HTML%20and%20CSS/) | The building blocks: headings, paragraphs, lists, images, and links |
| 3 | [Zoo Webpage](./Zoo%20Webpage/) | First JavaScript: a random-fact button and a day/night toggle |
| 4 | [Animal Card Grid](./Animal%20Card%20Grid/) | Looping over a list of data to build cards on the page |
| 5 | [Times Table Grid](./Times%20Table%20Grid/) | The classic counting `for` loop, and a loop inside a loop |
| 6 | [Savings Goal Counter](./Savings%20Goal%20Counter/) | The `while` loop, accumulators, and what makes a loop stop |
| 7 | [Quote Typer](./Quote%20Typer/) | Reacting to typing, with live correct/incorrect feedback |
| 8 | [Mad Libs](./Mad%20Libs/) | Reading several inputs and building a silly story from them |
| 9 | [Calculator](./Calculator/) | Reading inputs, a `switch`, and handling bad input |
| 10 | [Calculator Refactor](./Calculator%20Refactor/) | Functions that `return` values — and why return beats print |
| 11 | [Rock Paper Scissors](./Rock%20Paper%20Scissors/) | Game logic, random choices, and keeping score across rounds |
| 12 | [Playlist Stepper](./Playlist%20Stepper/) | Index arithmetic, array bounds, and off-by-one errors |
| 13 | [Choose Your Own Adventure](./Choose%20Your%20Own%20Adventure/) | Building a whole branching page from code |
| 14 | [Bug Hunt](./Bug%20Hunt/) | Debugging capstone: find and fix the four classic beginner bugs |
