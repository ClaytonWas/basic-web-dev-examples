Basic Web Dev Examples

Small, finished web pages for teaching the basics of HTML, CSS, and JavaScript. Click an example to open it. They build on each other, so this is a good order to teach them in.

1. Geological Wonders
HTML tables and CSS styling (no JavaScript yet).
2. Intro to HTML & CSS
The building blocks: headings, paragraphs, lists, images, and links.
3. Zoo Webpage
First JavaScript: a random-fact button and a day/night toggle.
4. Animal Card Grid
Looping over a list of data to build cards on the page.
5. Times Table Grid
The classic counting for loop, and a loop inside a loop.
6. Savings Goal Counter
The while loop, accumulators, and what makes a loop stop.
7. Quote Typer
Reacting to typing, with live correct/incorrect feedback.
8. Mad Libs
Reading several inputs and building a silly story from them.
9. Calculator
Reading inputs, a switch statement, and handling bad input.
10. Calculator Refactor
Functions that return values — and why return beats print.
11. Rock Paper Scissors
Game logic, random choices, and keeping score across rounds.
12. Playlist Stepper
Index arithmetic, array bounds, and off-by-one errors.
13. Choose Your Own Adventure
Building a whole branching page from code.
14. Bug Hunt
Debugging capstone: find and fix the four classic beginner bugs.

Each example folder has its own README with step-by-step teaching notes.
